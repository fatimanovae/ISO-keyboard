# iKeyboard AI (Android)

Dark iPhone-style keyboard for Android with soft click sounds and AI rewrite
(Professional / Casual / Longer / Funnier / Shorter / Fix grammar).

## Get the APK
**Option A - Android Studio:** open this folder -> wait for Gradle sync ->
Build > Build Bundle(s)/APK(s) > Build APK(s). File: app/build/outputs/apk/debug/app-debug.apk

**Option B - no Android Studio:** push this folder to a GitHub repo -> Actions tab ->
"Build APK" -> download the "ios-keyboard-apk" artifact.

## Install & set up
1. Copy the APK to the Pixel 9, tap it, allow "install unknown apps".
2. Open iKeyboard AI -> Enable keyboard -> Choose keyboard.
3. Paste your Claude API key in the app (Settings screen) for AI rewrite.
